Raspberry Pi 4 | Pi-hole DNS Server

Project Overview

Configured a Raspberry Pi 4 to run Pi-hole, a network-level DNS filtering and ad-blocking service.

Goal: Gain hands-on experience with Linux, DNS, network administration, and troubleshooting.

Hardware and Software

* Raspberry Pi 4
* 128 GB microSD card
* Ethernet connection
* Pi-hole
* Linux-based operating system

What I Accomplished

* Installed and configured Pi-hole on a Raspberry Pi.
* Verified that the DNS filtering service was running.
* Examined DHCP and DNS behavior on my home network.
* Practiced updating the system and checking installed packages.
* Tested network connectivity and web access.

Skills Demonstrated

* Linux administration
* DNS fundamentals
* Network troubleshooting
* System maintenance
* Raspberry Pi configuration

What I Learned

This project helped me understand how devices use DNS to access websites, how network-level filtering works, and how to maintain a Linux-based network service.
